## Descripcion Teslo Api
Api hecho con nest usando el type ORM usando de base de datos Postgres.

## Project setup
```bash
$ npm install
```

Ademas de tener sus configuraciones necesarias sobre el archivo ```.env```

# Imagen Docker Base de datos
Ya se tiene una configuración inicial sobre como levantar la imagen con el archivo de docker-compose.yaml

 - usar el siguiente comando:

```bash
$ docker compose up -d
```

## Compile and run the project

```bash
# development
$ npm run start
```
